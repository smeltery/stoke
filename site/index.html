03 / Good to know

A few practical
details.

A shared home, clear responsibilities, and documentation for the parts that matter.

Does Stoke replace Bellows or act?

Stoke assembles the source repositories and shared documentation. Bellows orchestrates workflows using act and Docker; Kiln supplies the runner image. Setup does not install the CLI or start Docker.

Is Kiln an Ubuntu runner?

Kiln runs Wolfi Linux with glibc and uses apk. Ubuntu-style tags are compatibility aliases. Workflows requiring apt, systemd or a complete hosted VM need adaptation.

Will updates overwrite my work?

Stoke skips dirty checkouts, feature branches and detached HEADs. Clean main branches update with fast-forward-only pulls. It never stashes, resets or switches branches.

Can I keep my hosted CI?

Yes. Local feedback complements hosted checks. Keep hosted CI for native platform behavior, GitHub integration and required merge checks. A Linux container does not emulate macOS.
