# Stoke documentation

Stoke brings Kiln and Bellows into one workspace for local GitHub Actions feedback.

Read the [documentation site](https://stoke-two.vercel.app/docs/) for the workspace,
Bellows and Kiln guides, command search and code examples. The site uses this
repository's Markdown and [pinned member snapshots](SOURCES.md).

- [Getting started](getting-started.md): workspace setup, runtime requirements and first run.
- [Usage](usage.md): safe updates and everyday workflow.
- [Configuration](configuration.md): fleet membership, runner mappings and privacy.
- [Architecture](architecture.md): how Stoke, Bellows, act, Docker and Kiln connect.
- [Troubleshooting](troubleshooting.md): missing tools, incompatible workflows and updates.
- [Development](development.md): Flox, checks, tests, site and brand assets.
- [Releases](releases.md): independent tool and image releases, and site deployment.
- [Brand library](../assets/brand/README.md): shared visual identity and downloads.

The member repos own the complete command and configuration references:
[Bellows documentation](https://github.com/smeltery/bellows/tree/main/docs) and
[Kiln documentation](https://github.com/smeltery/kiln/tree/main/docs).
